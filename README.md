# КЛЁВ — версия 2.0

Кликабельный MVP рыболовного навигатора для Москвы и Подмосковья.

## Что внутри

- Яндекс Карта;
- фильтры по рыбе, расстоянию и способу ловли;
- поиск по названию;
- карточки мест;
- подробное окно водоёма;
- маршруты через Яндекс Карты;
- избранное в браузере;
- адаптивный дизайн для iPhone;
- данные в отдельном файле `data/places.json`.

## Перед публикацией

1. Открой `index.html`.
2. Найди:

```html
https://api-maps.yandex.ru/2.1/?apikey=YOUR_YANDEX_API_KEY&lang=ru_RU
```

3. Замени `YOUR_YANDEX_API_KEY` на свой ключ Яндекс Карт.
4. В настройках ключа укажи домен GitHub Pages:

```text
sergeizh123.github.io
```

## Публикация на GitHub Pages

1. Загрузи содержимое архива в корень репозитория `Klev`.
2. Убедись, что `index.html` находится именно в корне.
3. Открой `Settings → Pages`.
4. В поле Source выбери `Deploy from a branch`.
5. Branch: `main`.
6. Folder: `/ (root)`.
7. Нажми `Save`.
8. Подожди 1–3 минуты.

Адрес сайта:

https://sergeizh123.github.io/Klev/
