# КЛЁВ — версия с бесплатной картой

В этой версии используется Leaflet + OpenStreetMap.

## Как загрузить на GitHub Pages

1. Распакуйте архив.
2. Загрузите `index.html`, `styles.css`, `app.js` в корень репозитория.
3. В GitHub откройте Settings → Pages.
4. Выберите Deploy from a branch → `main` → `/root`.
5. Сохраните и откройте адрес GitHub Pages.

## Важно

- API-ключ Яндекса не нужен.
- Карта использует публичные тайлы OpenStreetMap.
- Для коммерческого проекта и большой посещаемости позже лучше подключить отдельного tile-провайдера.
- Точки в `app.js` пока демонстрационные; их нужно заменить реальными местами и отчётами.
