# КЛЁВ — чистый дизайн с бесплатной картой

Вариант сайта в стиле предоставленного макета:
- Leaflet + OpenStreetMap;
- без API-ключа Яндекса;
- крупные фильтры;
- большая карта;
- карточки рыболовных мест;
- адаптация под iPhone.

## Загрузка

Загрузите `index.html`, `styles.css` и `app.js` в корень репозитория GitHub Pages.

## Важно

В подписи карты оставлена минимальная отметка `© OpenStreetMap`, потому что авторство OpenStreetMap должно сохраняться.
