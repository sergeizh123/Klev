# КЛЁВ — рыболовный навигатор

## Как запустить

1. Загрузите все файлы в корень репозитория GitHub.
2. В настройках репозитория откройте **Settings → Pages**.
3. В разделе **Build and deployment** выберите:
   - Source: **Deploy from a branch**
   - Branch: **main**
   - Folder: **/ (root)**
4. Нажмите **Save**.
5. Через 1–3 минуты сайт будет доступен по адресу:

`https://sergeizh123.github.io/Klev/`

Сейчас внутри демо-точки. Карта работает через Leaflet и OpenStreetMap.
